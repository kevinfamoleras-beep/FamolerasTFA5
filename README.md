# IT0049 TFA5 - Laravel POS Foundations

A simple four-page Laravel POS website featuring a landing page, about page, and two static-array account listings. Built for IT0049 TFA5.

## Requirements
- PHP and Composer compatible with the Laravel version installed (Laravel 13 requires PHP 8.3+).
- A local development environment and Git.

## Set up a fresh project
```bash
composer create-project laravel/laravel TFA5LaravelPOS
cd TFA5LaravelPOS
php artisan make:controller PageController
php artisan make:controller CustomerController
php artisan make:controller UserController
```
Copy the folders/files from this overlay pack into your Laravel project, merging/overwriting matching paths. **Do not replace your full Laravel project with this overlay; it is not the whole framework.**

Change the following in `.env` for a no-database demonstration:
```
APP_NAME="PC Parts POS"
SESSION_DRIVER=file
CACHE_STORE=file
QUEUE_CONNECTION=sync
```
Make sure `APP_KEY` has been generated by the installer; otherwise run `php artisan key:generate`.

Run:
```bash
php artisan optimize:clear
php artisan route:list
php artisan serve
```
Browse to `http://127.0.0.1:8000/`, `/about`, `/customers`, and `/users`.

## How it works
- `routes/web.php` maps each URL to a controller method.
- `PageController` renders Home and About.
- `CustomerController` defines five sample customers and passes them to `customers.blade.php`.
- `UserController` defines five sample users and passes them to `users.blade.php`.
- Blade templates extend `layouts/app.blade.php`, which provides the navigation and CSS.
- `@foreach` renders both static arrays.

## Optional database files
`database/migrations/2026_10_22_000000_create_pos_customers_table.php` and `database/seeders/PosDemoSeeder.php` are included for the submission's migration/seeder requirement. A fresh Laravel installation also includes its own default migration and `DatabaseSeeder.php` files. **The four pages do not read from the database**, so running migrations/seeders is not necessary to demonstrate TFA5. If desired and a database is configured, run `php artisan migrate` then `php artisan db:seed --class=PosDemoSeeder` (once).

## GitHub submission
From your project root, run:
```bash
git init
git add .
git commit -m "Build TFA5 four-page Laravel POS"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-NEW-REPO.git
git push -u origin main
```
If the repository already has a remote, inspect with `git remote -v` instead of adding another.
Do not commit `.env`, `vendor/`, `node_modules/`, or credential files. Keep `composer.json` and `composer.lock` in the repository.

## Hosting on InfinityFree
Official provider guide: https://forum.infinityfree.com/t/how-to-install-a-laravel-site-on-infinityfree/118578

1. Confirm the free host's PHP version supports your Laravel version; Laravel 13 needs PHP 8.3+.
2. Run `composer install --no-dev` and `php artisan optimize:clear` on your computer before uploading.
3. Upload the whole installed Laravel project **including** `vendor` and `.env` to `htdocs/` (do NOT flatten `public`).
4. In `htdocs/.htaccess`, paste the contents of `INFINITYFREE_HTDOCS_HTACCESS.txt`. Retain `htdocs/public/.htaccess` as Laravel generated it.
5. Configure hosted `.env` with `APP_ENV=production`, `APP_DEBUG=false`, `APP_URL=https://YOUR-DOMAIN`, `SESSION_DRIVER=file`, `CACHE_STORE=file`, `QUEUE_CONNECTION=sync`, and your valid `APP_KEY`.
6. Visit `/`, `/about`, `/customers`, and `/users` on the live domain.

This static demo has no requirement for a database connection. Laravel on InfinityFree has limitations; see provider's guide.
